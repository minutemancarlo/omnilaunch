# Changelog

All notable changes to **OmniLaunch** are documented in this file.
This project adheres to [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) and [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [1.2.2] - 2026-08-30

### 🛠️ Fixes & Reliability
- **Seamless 1-Click Update Installation**:
  - Fixed an issue where clicking "Install & Restart" caused Windows to display a path search error.
  - Updating now launches the setup installer smoothly and restarts OmniLaunch without interruptions.

### 🎨 UI & UX Polish
- **Streamlined Settings Interface**:
  - Cleaned up the Software Updates screen for public releases, removing unnecessary credential inputs.
- **Open Installer Folder Access**:
  - Added a dedicated "Open Folder" button in the update dialog to reveal the downloaded installer in Windows File Explorer anytime.

---

## [1.2.0] - 2026-08-30

### 🛡️ Features & Usability
- **Run as Administrator Option**:
  - Easily launch desktop applications and terminal scripts with elevated Administrator privileges whenever required (defaulted to unchecked for security).

### 🎨 UI & UX Polish
- **Amber Admin Shield Badges**:
  - Distinctive amber shield indicators highlight administrator-elevated apps across Workspace cards and Shortcut lists.

---

## [1.1.0] - 2026-08-30

### 🎨 UI & UX Polish
- **Emerald Animated Splash Screen**:
  - High-polish startup screen featuring glowing cosmic rings, floating supersonic brand emblem, and live status progress.
- **Titlebar Update Notification Pill**:
  - Animated glowing pill in the titlebar alerts you whenever a newer version is available.
- **In-App Changelog Viewer**:
  - Interactive changelog dialog accessible from the titlebar badge and Settings to browse updates directly.
- **Modern Transparent Brand Icon**:
  - Sleek transparent orbital chevron emblem and crisp system tray icon.

### 🚀 Features & Usability
- **Automatic Website Titles & High-Res Favicons**:
  - Entering any website URL automatically retrieves the official site name and high-definition icon.
- **Native Windows App Icon Detection**:
  - Automatically extracts and displays authentic high-resolution logos for installed Windows applications.
- **Enhanced Windows App Launching**:
  - Improved compatibility for Microsoft Teams, Windows Terminal, and application paths with spaces.

---

## [1.0.0] - 2026-08-18

### 🚀 Initial Release
- **Workspace Routine Orchestrator**:
  - Launch multi-app workspaces with a single click, custom staggered delays, and live status dots.
- **Quick Shortcuts Launchpad**:
  - Organized personal library of web links and apps with categories and clickable search tags.
- **Obsidian Dark & Modern Light Themes**:
  - Tailored dark and light aesthetics with fluid responsive grid layouts.
- **System Tray & Universal Hotkey**:
  - Quickly summon or hide OmniLaunch anytime with `Ctrl+Shift+Space`.
